GrowTH — ทดสอบเข้าสู่ระบบ

หน้านี้ยิง API ตรง ๆ ให้เห็นผลลัพธ์ ไม่ใช่หน้าจริงของแอป · ผลทุกคำขอโชว์ในกล่องดำด้านล่าง

ยังไม่ได้เข้าสู่ระบบ

เข้าสู่ระบบ POST /api/auth/login

ปุ่ม “โหลดบัญชีทดสอบ” อ่านข้อมูลจาก tests/demo_login.local.json และกรอกให้ทั้งช่องสมัครกับเข้าสู่ระบบ ไฟล์นี้ถูกกันออกจาก Git แล้ว
ลืมรหัสผ่าน: ลิงก์จะไปโผล่ใน console ของ uvicorn (ยังไม่ได้ตั้ง SMTP) คัดลอก token มาใส่ในกล่อง "ตั้งรหัสผ่านใหม่" ด้านล่าง

สมัครสมาชิก POST /api/auth/register

เข้าสู่ระบบด้วย Google POST /api/auth/google

ต้องใส่ Client ID เดียวกับ GOOGLE_CLIENT_IDS ใน .env และต้องเพิ่ม http://localhost:3000 ใน Authorized JavaScript origins ของ Google ด้วย ไม่งั้นปุ่มไม่ขึ้น

บัญชี GET /api/auth/me

ตั้งรหัสผ่านใหม่ POST /api/auth/password/reset
